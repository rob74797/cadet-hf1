# Real radio recordings

Put audio files of real radio traffic in this folder (upload them on GitHub with **Add file → Upload files**). On the next deploy they are listed automatically and the radio puts them on the air alongside its computer voices.

- **Formats:** MP3, M4A, AAC, WAV, OGG, Opus, WebM or FLAC, up to 8 MB each, up to 40 files.
- **Length:** 5 to 45 seconds works best: one over, or a short exchange. Longer files are cut to 45 seconds; silence at the start and end is trimmed.
- **Band (optional):** start the file name with a band to put it there, for example `40m-net-control.mp3` or `20m_dx-call.m4a`. Bands: 160m, 80m, 40m, 20m, 17m, 15m, 12m, 10m. Other names go wherever there are fewest recordings.
- **Audio:** plain demodulated receiver audio, as you'd record from the speaker or a line out. The radio does the rest: it shifts the voice when the cadet mistunes, and the wrong sideband loses it.
- **Permission:** use recordings you have the right to use, such as your own team's overs. If this repository is public, so are the files in it.
